# Preface Communications - Modern Web Application

A high-performance, responsive React web application built with **Vite**, **GSAP animations**, and multi-language support.

---

## 🚀 Features

* **GSAP Animations:** Smooth entrance animations for hero section and navigation elements.
* **Multi-Language Switcher:** Seamless translation support integrated via custom Google Translate wrapper.
* **Fully Responsive:** Customized mobile views with dedicated layout adjustments.
* **Interactive Modals:** Contact modal form and video showreel overlay with keyboard shortcuts (`ESC` to close).

---

## 🛠️ Tech Stack

* **Frontend Framework:** React 18+
* **Build Tool:** Vite
* **Animation Library:** GSAP (GreenSock)
* **Icons:** React Icons (`react-icons`)
* **Styling:** CSS3 (Variables, Flexbox, Grid, Media Queries)
* **Code Quality:** Oxlint / ESLint

---

## 📦 Getting Started

### Prerequisites
Make sure you have **Node.js** (v18 or higher) installed on your system.
